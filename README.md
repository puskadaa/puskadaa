## 🚀 Projetos em destaque

### 💰 App de Educação Financeira

Aplicativo Android desenvolvido como TCC com o objetivo de
auxiliar usuários a visualizar e compreender seus hábitos financeiros
através de movimentações simuladas.

**Principais funcionalidades:**

- 🔐 Cadastro e autenticação
- 💵 Configuração de fontes de renda
- 💸 Registro de receitas e despesas
- 🏷️ Categorias de transações
- 📊 Relatórios e gráficos
- ☁️ Persistência de dados com Firebase

**Tecnologias:** Kotlin • Android • Firebase
